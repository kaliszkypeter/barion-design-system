3 · Shape

7 · Buttons

8px radius for in-app product UI. Pill (999px) for onboarding-entry surfaces. Never use shadow on a button.

Primary CTAs (8px)
Secondary — White · Large · Medium · Small
Secondary — Light Blue (gentle CTAs)
Secondary — Red/Delete (destructive)
Onboarding-entry (pill)
Pill buttons (999px radius) are reserved for the onboarding entry flow — login email entry, post-login redirect to shop creation. Use 8px everywhere else.

8 · Tertiary links

Links are a distinct component family from buttons. Use for inline calls-to-action that don't need to look pressable — "See all", "Read the docs", "Cancel" in conversational flows. No pill shape, no fill, just text.

16 · Hard rules (v3)

✓ Primary in-app button: 8px radius, gradient #0074C7→#0097DB
✗ Pill primaries for in-app product UI (pill is onboarding-entry only)
✓ Flat: NO shadows on buttons, cards, inputs
✗ Shadow on any non-overlay (modal/dropdown/tooltip are the exceptions)
✓ Input focus: #0097DB border + 4px --shadow-focus halo
✗ Soft #66C1E9 border with no halo on focus
✓ Input: 6px radius, 16px Semilight, border #ECEDF1
✗ 8px input radius, Semibold body, dark #C4CAD7 border
✓ Status chips: --surface-status-* (saturated)
✗ Conflating chip surfaces with alert surfaces
✓ Sentence case everywhere — headings, buttons, nav, labels
✗ ALL CAPS labels (except acronyms: API, MFA, SCA, KYC)
✓ Shadows always rgba(44, 52, 70, …)
✗ Black shadows rgba(0, 0, 0, …)
✓ Disabled = token colours (--text-disabled)
✗ Disabled via opacity: 0.5
✓ Button transition: 300ms ease-in-out (--dur-button)
✗ Bounce / elastic / > 320ms animations
✓ Logos: SVG (assets/barion-*.svg) over PNG
✗ Glassmorphism, blur effects, frosted backgrounds, emoji in product UI
✓ Orange omitted from in-app (reserved for accent / marketing surfaces)
✗ Decorative orange or new orange CTAs in product UI
